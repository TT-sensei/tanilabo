# 単位研究所

小学校中学年〜高学年向けの、「数と単位をセットで考える力」を育てる静的Webアプリです。

## 6つのラボ

- 長さ（mm・cm・m・km）
- 水のかさ（mL・dL・L・kL）
- 重さ（mg・g・kg・t）
- 時間（秒・分・時間・日）
- 面積（cm²・m²・a・ha・km²）
- 体積（cm³・mL・L・m³）

## 学習モード

- ぴったり単位
- 単位チェンジ
- データ修理
- そろえてくらべる
- 小数研究
- 苦手特訓

各ラボは5モード×20問＝100問、全体で600問を収録しています。通常のチャレンジは毎回10問です。学習履歴・ラボ別の苦手問題・経験値・バッジはブラウザの `localStorage` に保存します。

NAVIキャラの日常学習シーンをラボカード・問題画面・結果画面に配置しています。効果音は外部ファイルを使わず Web Audio API で生成し、ヘッダーのスピーカーボタンから切り替えられます。

## 実行

`index.html` を開くだけで動作します。外部API・サーバー・データベース・ビルド処理は不要です。
